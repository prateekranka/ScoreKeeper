Referee Console

A compact official's console for a scorer who needs strong tables, decisive commands, and minimal visual ambiguity. It favors density because the scorer is already in the role of operator.

Positioning: a confident score desk for fast edits, clear standings, and audit-friendly round history.

Physical scene
Side table, overhead light, scorer checks every total
Target surface
iPhone 16 Pro on iOS 26+, 402 x 874 CSS px
Navigation model
Top status bar, tabs, command rail, dense detail pane
Motion posture
Direct state changes, 150 ms row updates, no page choreography

Tokens

Graphite shell, crisp slate surfaces, cyan active states, amber attention states, and strong line contrast.

Components

  • iOS 26-style glass treatment is reserved for bars and tappable controls.
  • Command bars for submit, undo, end, timer, dice, and log.
  • Editable data grids for scores and Phase 10 state.

States

  • Selected tabs and active commands use cyan with dark text.
  • Warnings use amber row badges before destructive choices.
  • Errors stay close to form rows and never hide behind modals.

Representative Screens

Every screen is built as a compact iPhone 16 Pro operations surface, with density coming from tables and command bars rather than stretched type.

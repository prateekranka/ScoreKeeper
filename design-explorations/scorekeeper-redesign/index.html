ScoreKeeper Redesign Explorations

Three independent product UI directions for the same iPhone 16 Pro, iOS 26+ app flows. These are static HTML mockups only: no SwiftUI implementation, no data model edits, and no API behavior changes.

Shared product assumption: small groups need to track casual games quickly, confidently, and without spreadsheet friction.

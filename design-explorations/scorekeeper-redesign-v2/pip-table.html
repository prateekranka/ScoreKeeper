Pip's Table

A tactile game-night system centered on Pip, a small score-token companion. It should feel social and memorable without sacrificing the fast score-entry job.

Mascot
Pip, the score token
Visual asset language
Lacquer tokens, table light, tally slips
Motion
Gentle token bob, score pop, drifting table tokens

Design System

Deep green tabletop shell, ivory score sheets, lacquer red highlights, and solid panels for score legibility.

Components

Companion hero, tally rows, token actions, roster slips, bottom thumb-zone submit controls.

iOS 26+

Glass-like controls live in status bars, chips, and buttons only. Main score content remains opaque.

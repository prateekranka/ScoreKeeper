# PipCount redesign loop

This folder contains the static Paper Bauhaus prototype and the prompts used for its
design-review loop. Local logs, generated iteration snapshots, and nested tool
checkouts are intentionally excluded.

The files under `app/context/emil/` and the derived motion notes use material from
Emil Kowalski's `skills` repository at commit `78761e1`. See `LICENSE-EMIL-SKILLS`.
